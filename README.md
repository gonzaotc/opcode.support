# EVM Opcode Support Report

Which EVM opcodes are supported on which chains, measured against live nodes instead of read off
documentation.

- **Last updated:** 2026-08-20T17:50:04.448Z
- **Refreshed:** daily at 06:00 UTC, and on demand after a hardfork
- **How this is measured:** [METHOD.md](./METHOD.md)

Cells: `yes` supported, `no` unsupported, `?` no verdict, `*` from a primary source because no
probe reaches that chain. Generated by `npm run report`, do not edit by hand.

## Representativeness

The top 50 EVM chains by TVL, as ranked by DefiLlama. Chains that produced a verdict hold $64.5B, **91.4% of EVM TVL**. Chains we could not scan do not count: Tron, Robinhood Chain, Anubis.
